---
name: veridia-session-ask
description: Ask questions from session state.
---

Asks clarifying questions based on the session type and level. Collects answers interactively and writes them to .veridia/session.json. Advances session step to do. Skips automatically when level is 2 or higher.

**Usage**: `veridia session-ask`

**Example**:
```bash
veridia session-ask
```
