# Naming

## Decision
- **Project name:** `veridia`
- **Reason:** short, brandable, evokes *verify* / *varitas* (truth) — the
  verification-first mechanic is our most defensible differentiator.

## Availability (checked)
- npm: `veridia` — **free**
- GitHub user/org: `veridia` — **free**

## Naming rules for this project
- Must stay free on npm registry and GitHub.
- Prefer short, brandable, derivable (veridia → veri-/verify family).
- Avoid names already used by other AI/spec tools.
