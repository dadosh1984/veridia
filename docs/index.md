# veridia

**Model-agnostic quality through mechanics, not through the model.**

veridia is a CLI tool that classifies a task, decides what can actually be verified,
runs the cheapest sufficient model over it, and measures its own misses.

## The one-word identity: **triage**

veridia does not "understand you." It *sorts well*: task → verifiability → process → model → check.
